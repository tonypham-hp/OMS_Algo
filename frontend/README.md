# OMS Frontend

Giao diện Advanced Order Management cho HOSE, chạy bằng dữ liệu mô phỏng. Đặc tả: [docs/frontend-spec.md](../docs/frontend-spec.md).

```bash
npm install
npm run dev     # chạy dev
npm run lint    # ESLint
npm run test    # Vitest
npm run build   # kiểm tra kiểu và build
```

Tài khoản demo ở trang đăng nhập: `khachhang`, `dealer`, `vanhanh`.
